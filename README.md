# Note's

Кроссплатформенное приложение для ведения заметок. Разработано для Linux, Windows и Android с упором на локальное хранение данных, поддержку Markdown и удобство работы на десктопе.

## Основные возможности

* **Локальное хранение:** Заметки хранятся исключительно на устройстве в базе данных SQLite. Облачная синхронизация и телеметрия отсутствуют.
* **Поддержка Markdown:** Базовое форматирование текста, списки, выделение кода и режим предпросмотра.
* **Адаптивный интерфейс:** Дизайн на базе Material 3, адаптирующийся под мобильные и десктопные экраны. Поддерживаются светлая и темная темы.
* **Структуризация:** Распределение заметок по категориям (создаются динамически), закрепление важных записей и отдельный архив.
* **Резервное копирование:** Экспорт всей базы данных в `.json` для ручного переноса между устройствами и сохранение отдельных заметок в формат `.md`.

## Горячие клавиши (PC)

Для пользователей Windows и Linux предусмотрены базовые шорткаты:

| Комбинация | Действие | Контекст | 
| ----- | ----- | ----- | 
| `Ctrl` + `N` | Создать новую заметку | Главный экран | 
| `Ctrl` + `S` | Сохранить изменения | Редактор заметок | 
| `Ctrl` + `P` | Переключить режим (Редактор / Markdown) | Редактор заметок | 
| `Esc` | Закрыть редактор (с подтверждением отмены) | Редактор заметок | 

## Используемые технологии

* **Фреймворк:** [Flutter](https://flutter.dev/)
* **База данных:** `sqflite` (Android) / `sqflite_common_ffi` (Windows/Linux)
* **Стейт-менеджмент:** `provider`
* **Файловая система:** `file_selector`
* **Рендер Markdown:** `flutter_markdown`

## Сборка и запуск

**Требования:**
* Установленный [Flutter SDK](https://docs.flutter.dev/get-started/install)
* Настроенное окружение для целевой платформы (Linux, Windows или Android)

**Инструкция:**
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Motras06/Note-s
   cd notes
   ```
2. Установите зависимости:
   ```bash
   flutter pub get
   ```
3. Запустите проект для нужной платформы:
   ```bash
   # Для Linux
   flutter run -d linux
   
   # Для Windows
   flutter run -d windows
   
   # Для Android
   flutter run -d android
   ```
